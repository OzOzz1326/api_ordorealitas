# Ordo Realitas - API

## Uma API para jogadores de Ordem Paranormal - **Projeto de Fã**

### Objetivo
Tenho como objetivo a prática de desenvolvimento de API's como mostrado em minhas aulas. Projeto sem fins lucrativos.

Essa API terá como base o sistema de Ordem Paranormal I e contará com:
- Criaturas
- Rituais
- Poderes Paranormais
- Itens Amaldiçoados
- Ameaças da Realidade
